## Phase 0：Day 1 — 上线 GitHub

### 你负责的三件事

- [ ] 📋 **注册 GitHub 组织**
  - 名称建议: `lingcheck-io` 或 `lingcheckhq`
  - 地址: https://github.com/organizations/plan/free
  - 注册完告诉我组织名

- [ ] 📋 **生成 GitHub Personal Access Token (PAT)**
  - 地址: https://github.com/settings/tokens
  - 勾选权限: `repo`（全部）+ `workflow`
  - Token 复制给我，我用完即删
  - 安全说明：我只会用它 push 代码和配置 Action，不会做任何其他操作

- [ ] 📋 **拉一个微信群**
  - 群名建议: "灵测内测群"
  - 拉 10-20 个你认识的程序员朋友
  - 把我通过 webhook 拉进去（我来配置）
  - 群公告写："这是一个 AI 代码审查工具的内测群，大家随便提需求、随便骂"

### 我同步做的三件事

- [ ] 🤖 推代码到 GitHub（等你给 Token）
- [ ] 🤖 配置 GitHub Action workflow
- [ ] 🤖 配置 Issue 模板 + PR 模板
- [ ] 🤖 在群里发第一条产品演示消息
